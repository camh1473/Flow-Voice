# Flow Voice 0.1.0

First public release: local voice dictation for Windows. Hold a key, talk, and the text is pasted where you are typing. Speech recognition runs on your PC with Whisper; nothing is sent to a cloud service.

## Which file?

- **FlowVoice-0.1.0-Setup.exe** (~500 MB): everything included, works offline from the first launch.
- **FlowVoice-0.1.0-Setup-Lite.exe** (~95 MB): small. The first launch downloads the speech model once (about 460 MB, a few minutes).

Windows 10 or 11, 64-bit. Installs for your user only (no administrator rights). Your settings and history stay in `%APPDATA%\FlowVoice` when you update or uninstall.

## Please read

- **Windows will warn you.** The installers are not code-signed, so SmartScreen shows "Windows protected your PC". Choose **More info > Run anyway**. Some antivirus programs also flag apps built with PyInstaller by mistake.
- **Check your download** against `SHA256SUMS.txt` (`Get-FileHash <file>` in PowerShell).
- **Update check:** about once a day the app asks GitHub for the latest release and, if there is a newer one, adds "Download update" to the tray menu. Nothing about you is sent and nothing installs by itself. Turn it off in Settings > Interface.

## What is in it

- Push-to-talk and hands-free dictation, spoken commands, filler and backtrack handling ("scratch that" erases only the last phrase), dictionary, snippets, automatic lists and question marks, optional local AI polish (Ollama), read-aloud, history.
- New pill: a round mic icon that turns into fine glowing threads while you talk, and stays above other windows.
- Self-healing microphone, a single running copy, and a crash log in `%APPDATA%\FlowVoice\flowvoice.log`.
